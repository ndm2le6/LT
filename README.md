# Iron AI Coach - Calendar Flow

App Android Java theo luồng:
0 Day calendar -> Bắt đầu -> nhập cân nặng/chiều cao -> chọn phút -> AI phân tích -> bài tập có timer/video -> camera check-in -> hiệu ứng xé lịch +1 Day -> lịch sử kiểu giao dịch ngân hàng.

## Build bằng GitHub
1. Upload toàn bộ thư mục này lên GitHub.
2. Vào Actions -> Build APK -> Run workflow.
3. Tải file APK trong Artifacts.

## Gemini API
Mở tab Dữ liệu trong app để nhập API key Gemini và model. Mặc định: gemini-2.5-flash.
